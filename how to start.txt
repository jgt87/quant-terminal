Normal use: double-click Start Terminal.cmd in the Quant Terminal folder. It updates to the latest release (when installed with git clone; set QT_NO_UPDATE=1 to turn this off), installs the dependencies, rebuilds the app, starts the local server and opens http://localhost:4180 in your browser once it is ready. Needs Node.js 20.19+ or 22.12+ (the current LTS from https://nodejs.org). Keep the window open while you use the terminal; closing it stops the server. After an update the window shows what is new. To only check this computer, run Start Terminal.cmd --check from a command prompt.

With live FX from Deriv (no account needed): double-click Start Terminal (Deriv FX).cmd. Forex pairs such as EURUSD=X then come from Deriv's public feed with live ticks (history goes back one year; needs Node.js 22 or newer). Deriv symbols also work in the normal launcher as DERIV:EURUSD, DERIV:XAUUSD and so on.

With live FX from MetaTrader 5: open MT5 and log in first, then double-click Start Terminal (MT5).cmd. The first time, it sets up the bridge's Python environment (bridge\.venv), which needs 64-bit Python 3.12 (https://www.python.org/downloads/, with the py launcher).

From a terminal, run these from the Quant Terminal folder:
npm install
npm run build
npm start
Then open http://localhost:4180.

While developing: npm run dev gives hot reload at http://localhost:5180. If you keep using :4180 instead, also run npx vite build --watch inside web\, or your changes won't show up there.

Don't open web/index.html directly: it's only the build template, and the app needs the local server for its data.
