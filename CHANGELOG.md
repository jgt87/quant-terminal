## v0.2.0 — 2026-11-06

- Indicators: 42 new built-in indicators (54 in total), from public formula definitions, in the indicator picker and as alert operands, with default colors. Moving averages: DEMA, TEMA, Hull, ALMA, KAMA, Least Squares (LSMA), Smoothed (SMMA), Volume Weighted (VWMA). Trend and bands: Keltner Channels, Envelope, Ichimoku Cloud (conversion, base, lagging span, leading spans with cloud fill; the cloud ahead of the last bar is not drawn yet), SuperTrend, Parabolic SAR, Chandelier Exit. Momentum: Stochastic RSI, CCI, Williams %R, Rate of Change, Momentum, Awesome Oscillator, TRIX, Ultimate Oscillator, Chande Momentum, Detrended Price Oscillator, True Strength Index, Coppock Curve. Trend strength: DMI (+DI, −DI, ADX), ADX, Aroon, Aroon Oscillator, Vortex, Choppiness Index. Volatility: Historical Volatility, Bollinger %B, Bollinger Bandwidth. Volume: Money Flow Index, Chaikin Money Flow, Accumulation/Distribution, Chaikin Oscillator, Elder Force Index, Ease of Movement, Price Volume Trend. Code in `core/src/indicators/` (`movingAverages`, `directional`, `momentum`, `bands`, `volumeFlow`, shared helpers in `series`); tests in `core/test/indicators-extended.test.ts`.
- User scripts: `ta` adds `wma`, `rma`, `hma`, `roc`, `cci`, `dmi`, `williamsR`, `mfi`, `psar`, `supertrend` and `keltner`.
- Ichimoku: the cloud now runs 25 bars past the last bar and is filled green where span A is above span B and red where it is below. Indicator outputs can be marked `forward` (values past the last bar); the time axis labels the empty space right of the last bar with projected times.
- Chart types: Volume candles (body width by volume), HLC area, High-low, Line with markers and Step line.
- Panes and scales: move an indicator to the price pane, a new pane or the pane of another indicator (indicator menu, Move to); draw an indicator on its own scale (Scale, Own scale); maximise a pane (Ctrl+double-click, or the indicator / price axis menu) and collapse indicator panes to their legend row; Indexed to 100 and Invert scale modes for the price scale (axis menu and Chart settings).
- Multi-chart: Time sync toggle in the top toolbar: scrolling or zooming one chart shows the same time range on every chart of the tab (link groups with the time toggle still sync on their own); turning it on aligns the charts to the active one.
- Order flow (Binance symbols), chart menu Order flow: Footprint (sell × buy volume per price level, diagonal imbalances, point of control, bar delta; shown when bars are at least 34 px wide), Volume bubbles on the busiest price levels, Delta and Cumulative delta panes (taker buy − sell volume from Binance klines). New Time and sales panel (Alt+Shift+8): latest trades with aggressor side, large prints, buy / sell totals and a size filter. Server: `/api/orderflow/flow`, `/api/orderflow/footprint` (from aggTrades, closed bars cached, returns only fully covered bars plus where to continue) and `/api/orderflow/trades`; core `orderflow` module.
- Paper trading on the chart (simulated): the selected paper account's working orders, stop-limit triggers, bracket stop-loss / take-profit legs and the open position are drawn as lines on the price pane with labels and P&L. Drag a line to move the order (prices round to the scale's decimals); the × button cancels an order, removes a bracket leg or closes the position. Overlapping labels are staggered. New stop-limit order type (ticket, simulator) and `PUT /api/paper/:id/orders/:orderId` to change a working order.
- Bar Replay: Ticks option (Binance and MT5 symbols). While playing, each next bar is built from its recorded ticks (Binance trades, MT5 ticks) and forms on the chart before it steps; about two seconds per bar at 1×. Bars without ticks are revealed whole. Server `/api/ticks`; MT5 bridge `/ticks` (read-only `copy_ticks_from`).
- Presentation: High contrast theme (black background, white text, bright up/down colors, yellow accent) for the chart and the app; the theme button cycles dark → light → high contrast. Save image (SVG) in the chart menu: the chart drawn as vector SVG through a recording 2D context, with the same header as the PNG. New Data table panel (Alt+Shift+9, chart menu Data table): every loaded bar with OHLCV and the visible indicator values, newest first, virtualised; click a row to show that bar, copy or download as CSV.
- Fix: a fresh clone builds again. The `data/` rule in `.gitignore` was meant for the runtime data directory but also matched `web/src/data/`, so its modules (`intervalSpec`, `seriesSource`, `comparePaging`, `compose`, `sessions`) were never committed; the rule is now anchored to `/data/` and the modules are in the repository (#1, #2).
- Fix: `server` and `web` depend on `@qt/core` as `*`, so npm always links the local `core` workspace instead of requesting the package from the public registry when the versions differ (#1, #2).
